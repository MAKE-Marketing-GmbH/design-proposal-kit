# design-proposal-kit — Design-Vorschlag aus einem Brief

Werkzeug, das aus einem Design-Brief ein vorzeigbares Design-Angebot macht:
Stilrichtungen als „Bundles" bündeln und als PDF-Angebot aufbereiten.

- **Für wen:** MAKE-intern, für Kunden-Angebote im Web-Design.
- **Remote:** `MAKE-Marketing-GmbH/design-proposal-kit` (öffentlich)

## Was im Repo liegt

| Pfad | Was |
|---|---|
| `example/bundles/` | Beispiel-Bundles (z. B. `warm-and-playful`, `bright-and-photographic`) mit Belegbildern je Stil |

Das Werkzeug selbst ist als Skill dokumentiert; dieses Repo hält die
Beispiel-Bundles und die Vorlagen.

## Offen

Das Repo enthält nur die Beispiele. Die eigentliche Skill-Dokumentation liegt
außerhalb — beim nächsten Anfassen hierher verlinken oder mit aufnehmen.
